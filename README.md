# Flashcards hébreu

Apprentissage de l'hébreu moderne en français : carnet de grammaire et de vocabulaire,
flashcards, lexique imprimable.

- L'app : https://rubischthagadol.github.io/flashcards-hebreu/
- Le lexique imprimable (PDF) : https://rubischthagadol.github.io/flashcards-hebreu/lexique.pdf

Ce dépôt ne contient que les fichiers publiés.

## Sources

Les graphies pleines (l'hébreu sans nikoud) de l'app et du carnet viennent d'un lexique vérifié
mot à mot sur :

- Pealim : https://www.pealim.com/ ;
- le Wiktionnaire hébreu (https://he.wiktionary.org/) et le Wiktionnaire anglais
  (https://en.wiktionary.org/), ce dernier lu dans son extraction par kaikki.org
  (https://kaikki.org/) ;
- Hspell, le correcteur orthographique de l'hébreu : http://hspell.ivrix.org.il/.
